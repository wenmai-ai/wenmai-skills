# Wenmai Alpha Youtube Scraper

## Purpose
Use this Skill to fetch Youtube Scraper data through Wenmai standard API. It is useful for YouTube 视频、频道、搜索或评论.

The Skill calls exactly one fixed standard API endpoint:

- Endpoint: `POST /wmapi/v1/alpha/youtube-scraper`
- Auth: Header `secret-key: $WENMAI_API_KEY`
- Script: `scripts/alpha_youtube_scraper.py`

## How To Run

请参考 https://skill.wenmai-ai.com/wenmaiskills/use_guide.html 获取 `secret-key`；额度或余额不足时，按该指南完成充值。运行脚本前，把复制的 key 导出为 `WENMAI_API_KEY`（或 `WENMAI_SECRET_KEY`）。

```bash
export WENMAI_API_KEY=sk-...
python3 scripts/alpha_youtube_scraper.py '{"is3D": false, "is4K": false, "isHD": false, "hasCC": false, "is360": false, "isHDR": false, "isLive": false, "isVR180": false, "isBought": false, "videoType": "video", "dateFilter": "month", "maxResults": 3, "hasLocation": false, "hasSubtitles": false, "lengthFilter": "between420", "sortVideosBy": "NEWEST", "sortingOrder": "relevance", "saveSubsToKVS": false, "searchQueries": ["Crawlee"], "subtitlesFormat": "srt", "maxResultStreams": 0, "maxResultsShorts": 0, "downloadSubtitles": false, "subtitlesLanguage": "en", "preferAutoGeneratedSubtitles": false}'
```

The script prints the raw Wenmai API response as formatted JSON. Read `references/api.md` when you need parameter details, field meanings, allowed values, defaults, request examples, or response fields.
