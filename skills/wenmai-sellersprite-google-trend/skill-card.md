# 稳卖 SellerSprite google trend

用于查询 Google Trends 中指定关键词在特定市场的搜索热度变化趋势

- Runtime: Wenmai standard API `POST /wmapi/v1/sellersprite/google-trend`
- Supplier: `SELLERSPRITE`
- API: `google_trend`
- Script: `scripts/google_trend.py`
- Auth: `WENMAI_API_KEY` sent as `secret-key`; see the usage guide at https://skill.wenmai-ai.com/wenmaiskills/use_guide.html to get the key and recharge
