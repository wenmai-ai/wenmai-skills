# Wenmai JIIMORE 批量查询关键词指标

通过一个固定 Wenmai standard API 端点执行 `jiimore_search_keywords_batch`。

- Endpoint: `POST /wmapi/v1/jiimore/keywords-batch`
- Script: `scripts/jiimore_search_keywords_batch.py`
- Auth: `WENMAI_API_KEY` 作为 `secret-key`
- 凭据/充值：https://skill.wenmai-ai.com/wenmaiskills/use_guide.html
